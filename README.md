# Allur Smart Factory — MVP для кейса №2

Помощник начальника смены: за одну минуту ответить, **где проблема, чем она подтверждается, что может произойти, что делать и как изменился результат**.

Цепочка: обзор завода → отклонение → доказательства → прогноз или сравнение вариантов → действие с подтверждением → отчёт.

> Учебный MVP хакатона. Все производственные данные синтетические или тестовые данные задания. Это не заводская система Allur, не CAD Kia и не руководство по ремонту.

## Три источника данных (не смешиваются)
| Источник | Метка в интерфейсе | Что показывает |
|---|---|---|
| Данные кейса | «Тестовые данные задания. Не подтверждённые реальные показатели Allur» | выпуск, брак, простои и планы из задания; отклонения с исходными записями |
| Симуляция | «Синтетическая симуляция» | цех со сменой 08:00–16:00, автомобили `DEMO-xxx`, отказы оборудования, решения |
| Видеоэксперимент | «Внешняя запись. Не производство Allur. Воспроизведение результатов анализа» | результаты анализа внешней записи (YOLOX-S + трекер): время присутствия машин в зоне |

При смене источника сбрасываются выбор, фильтры, контекст чата и прежнее AI-объяснение. Видео не меняет выпуск, OEE и оборудование симуляции.

## Разделы
- **Обзор** (`#overview`) — переключатель «Данные кейса / Симуляция», ключевые показатели, карта участков, приоритетные проблемы и следующий шаг.
- **Цеха** — объёмная карта предприятия и цехов, автомобили Kia, 3D-осмотр с открытием капота.
- **Отчёт**:
  - данные кейса (CSV, печать в PDF);
  - передача смены (JSON, CSV);
  - результаты смены;
  - «Эффект» — измерено отдельно, деньги только по введённой пользователем стоимости.
- **Ещё** — задачи и решения, автомобили, задания, модели, видеоэксперимент.

Выпуск этапов не суммируется, проценты не усредняются — доли считаются по суммам количеств.

## Запуск (Windows, Node.js ≥ 22, без npm-зависимостей)
```powershell
npm.cmd run build
npm.cmd start
```
Открыть http://localhost:3000/#overview. Без ключей AI работает локальное объяснение — основной сценарий от внешних API не зависит.

Проверочный запуск на свободном порту с отдельной сменой:
```powershell
$env:PORT='3028'; $env:AI_PROVIDER='local'; $env:ALLUR_STATE_FILE='check-3028.json'; node server/index.mjs
```

## Проверки
```powershell
npm.cmd test          # node --test, все тесты
npm.cmd run build     # сборка dist/ и проверка синтаксиса
npm.cmd run policies  # стратегии на 200 синтетических сменах → reports/policy-comparison.*
npm.cmd run train     # модель риска подъёмника (синтетическая) → models/lift-risk-v1.json
```
Видео: `vision/` (Python, ONNX). Модель и запись лежат вне репозитория, см. `vision/README.md`. Ручная сверка: `presentation/verification/results.md`.

## Ограничения
- Данные кейса — два дня тестовых записей; прогноз по ним не строится, только сценарий с явными допущениями.
- Симуляция — синтетическая, с одним видом отказа оборудования; эффект измерен на ней, а не на заводе.
- Видео: одна внешняя запись, окно измерения 0–21,8 с (дальше камера движется), 5 размеченных вручную посещений. Это не общая точность системы. `car-N` — не VIN.
- Причины не устанавливаются: гипотезы показаны отдельно от фактов.

## Структура
| Где | Что |
|---|---|
| `server/` | HTTP и защита (Host/Origin, CSRF, CSP), движок смены, KPI, решения, AI-адаптеры |
| `public/app/NN-*.js` | части клиента, сборка склеивает их в `dist/app.js` |

| `presentation/` | слайды, речь, скриншоты, сверка видео |
| `tests/` | тесты `node --test` |
