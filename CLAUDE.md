# Allur Smart Factory — инструкции для Claude

**Прежде чем что-либо делать, прочитай `HANDOFF.md`** (состояние проекта, история, незавершённые этапы) и `CONTRIBUTING.md` (командная работа, зоны, части клиента `public/app/`).

## Правила
- Общайся с пользователем по-русски. Все производственные данные синтетические; не выдавай их за данные Allur.
- **`.env`:** не читать, не выводить, не менять. В нём может быть действующий OpenAI-ключ. Ключи не попадают в ответы, файлы, снимки, коммиты.
- **Порты:** не останавливай чужие процессы на 3000/3001. Свои проверки — с порта 3027. Проверочный запуск без платного AI:
  `$env:PORT='3027'; $env:AI_PROVIDER='local'; $env:ALLUR_STATE_FILE='check-3027.json'; node server/index.mjs`
- **Git:** не делать `git reset/clean`. Работа идёт через ветки и pull request в `ab0ka/ALLUR-SMART-FACTORY`; напрямую в `main` не пушить. Коммит, push ветки и открытие PR — только по просьбе пользователя.
- **Клиент:** скрипт собран из частей `public/app/NN-*.js` (сборка склеивает их по порядку имён в `dist/app.js`); отдельного `public/app.js` нет.
- **Движок и защита:** не переписывать производственный движок ради визуализации. Сохранять диагностику, решения, чат, серверную защиту (Host/Origin/CSRF/CSP; inline-стили запрещены).
- **Проверки:** `npm.cmd test` (на 8 октября 2026: 86/86) и `npm.cmd run build`. Используй `npm.cmd`, а не `npm`.
