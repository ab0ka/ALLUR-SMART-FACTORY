# Allur Smart Factory — инструкции для Claude

Синтетическая учебная симуляция цеха сборки с игровым изометрическим интерфейсом и 3D-карточкой автомобиля. Node.js ≥ 22 (у нас 24), vanilla JS, **без npm-зависимостей в рантайме**.

**Перед работой прочитай:** `HANDOFF.md` (состояние, история, незавершённое; раздел 0d — самое свежее), `CONTRIBUTING.md` (ветки, зоны, кто чем занимается), при задачах по 3D — `docs/ASSETS.md`.

## Правила (обязательно)
- Общайся с пользователем по-русски. Пользователь — Абзал (`ab0ka`), владелец репозитория и проверяющий PR.
- Все производственные данные синтетические (`DEMO-xxx`, условные посты и нормативы). Не выдавай их за данные Allur. 3D-модель — учебная, не CAD Kia/Allur; в интерфейсе метка «Синтетическая учебная симуляция. Не является руководством по ремонту».
- **`.env`:** не читать, не выводить, не менять. В нём может быть действующий OpenAI-ключ. Ключи не попадают в ответы, файлы, снимки, скриншоты, коммиты, `data/`.
- **Порты:** не останавливай чужие процессы на 3000/3001 (демо пользователя). Свои проверки — с 3027 и выше. Проверочный запуск без платного AI (`node` напрямую не читает `.env`):
  `$env:PORT='3027'; $env:AI_PROVIDER='local'; $env:ALLUR_STATE_FILE='check-3027.json'; node server/index.mjs`
  То же в `.claude/launch.json` → конфигурация `allur-check-3027` (для `preview_start`). Временные серверы после проверки останавливай.
- **Git:** не делать `git reset/clean`, не перезаписывать чужую работу. Работа — через ветки и pull request в `ab0ka/ALLUR-SMART-FACTORY`; напрямую в `main` не пушить. Коммит, push, открытие и слияние PR — **только по просьбе пользователя**. Одна задача — одна ветка — один PR, в описании `Closes #N`.
- **Движок:** не переписывать производственный движок ради визуализации. Новые возможности движка — аддитивно и с тестами. Интерфейс рисует только снимок сервера; клиентской симуляции нет. Изменения производства — только через подтверждение и `requestId` (идемпотентность).
- **Защита:** не ослаблять Host/Origin/Sec-Fetch, CSRF, лимит тела, белый список статики, CSP `script-src 'self'; style-src 'self'`. **Inline-стили и import map запрещены** — только классы в `public/styles.css`, SVG-атрибуты, CSSOM.
- Скачанные файлы и сторонние модели — только через пользователя (вход на сайты, авторизация — не обходить). Исходники моделей лежат в `assets-src/` (в `.gitignore`); лицензию и атрибуцию фиксировать в `docs/ASSETS.md`.

## Полезное
- Ссылки внутри интерфейса: `#space/<space>/<vehicle|post|problem|compare|chat|car3d>/<id>`. Смена только `#` не перезагружает страницу — после пересборки делай `location.reload()`.
- Скриншоты встроенного браузера при ширине ≥ 1280 бывают обрезаны, а скрытая панель останавливает `requestAnimationFrame`. Геометрию проверяй через JS (`getBoundingClientRect`, `scrollWidth`); анимацию и WebGL — в headless Edge через CDP с `--use-angle=swiftshader`.
- Bash-heredoc с обратными кавычками портит текст — для сложных правок используй Edit/Write или скрипт-файл в scratchpad.
- Скриншоты для PR и отчётов — в `screenshots/`.
