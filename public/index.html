    Определения метрик

    Плановое время поста — прошедшие минуты смены. A = минуты работы / плановое время; все остановки — неисправность, работы техника, нет автомобиля на входе, блокировка следующим буфером — потери доступности, показаны раздельно.

    P = нормативная работа / минуты работы (снижение темпа и износ подъёмника уменьшают P). Q поста = (выполненные операции − операции на автомобилях, у которых контроль выявил дефект этого участка именно с этого поста) / выполненные операции. Для контроля, доработки и отгрузки Q = 100%: они не создают продукцию. Доработка не считается выпуском. OEE = A × P × Q по каждому посту; среднего «OEE завода» нет — общий выпуск показан отдельно.

    Принято — автомобили, прошедшие контроль; каждый засчитывается один раз, после доработки — только при успешном повторном контроле. Доля годных с первого предъявления = прошедшие первый контроль / впервые проверенные. План смены задаёт оператор. Эталонная мощность — прогон того же движка без отклонений оборудования и инцидентов с типовой долей брака 15%. Прогноз — прогон копий текущего состояния по гипотезам причин без новых вмешательств.

        Число наблюдаемых объектов в зоне по времени

        Посещения зон

        Незавершённые посещения

        Наблюдаемая длительность — время, когда объект виден в зоне на записи; это не подтверждённое время операции. Превышение = max(0, наблюдаемая длительность − порог). Для потерянных и оставшихся в зоне объектов это нижняя оценка. OEE, брак и вероятность поломки по рамкам видео не рассчитываются.
