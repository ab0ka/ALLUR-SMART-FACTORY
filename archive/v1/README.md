# Архив v1 — синхронная линия (не используется)

Копия первой версии MVP до перехода на мастерскую с отдельными автомобилями (этап 1 WORKSHOP_SPEC.md).
Синтетический счётчик линии на 400 машин, прежний UI и тесты движка. Эти файлы не импортируются сервером,
не попадают в `dist` и не запускаются `npm test` (тесты ищутся только в `tests/`). Сохранены, потому что в Git
ещё нет коммитов и иначе прежний код был бы потерян. Все данные синтетические.
