# Проверка видеоаналитики: ручная разметка против системы

**Запись:** «Cars Waiting in a Traffic Light» (Erkan Avanoğlu, Pexels, лицензия Pexels), 23,99 с, 1920×1080 — реальная, не производство и не Allur. **Система:** `vision/` (YOLOX-S + трекер в стиле ByteTrack), прогон 8 октября 2026, `vision/out/analysis.json`, зона «Зона ожидания перед перекрёстком».

## Как размечали
- Разметчик: ассистент Claude, **визуально по кадрам** (`frames/*.jpg`: только зона и время, без рамок модели), шаг 0,2 с у каждого перехода. Это не независимый человек, и результаты системы были видны до разметки — возможна предвзятость. Рекомендуется перепроверка человеком по тем же листам кадров.
- Правило: посещение — пока точка касания машины с дорогой (середина низа) внутри зоны; уход за край кадра — конец видимости.
- **Окно проверки 0–21,8 с.** Примерно с 21,8–22,0 с машина с камерой трогается на зелёный, камера движется, и зона в координатах кадра перестаёт соответствовать месту на дороге. Всё после 21,8 с не оценивалось.
- Отдельного фрагмента для проверки нет: запись одна, 24 с; зону и пороги ставили по ней же.

## Выборка
5 ручных посещений на 21,8 с видео: 3 машины ждут у светофора (длинные), 2 машины пересекают перекрёсток у левого края (короткие). 3 машины, едущие по самой линии зоны, вручную однозначно не решить — помечены как спорные и в разметку не включены.

## Результат (`node presentation/tools/compare.mjs presentation/verification/reference.csv vision/out/analysis.json --window 0,21.8`, порог сопоставления IoU ≥ 0,3, задан заранее)

| Показатель | Значение |
|---|---|
| Ручных посещений | 5 |
| Посещений у системы в окне | 8 |
| Совпало | 4 |
| Пропущено | 1 — тёмный седан у левого края (4,4–4,8 с) |
| Лишних | 4 |
| Ошибка длительности по совпавшим, с | медиана 0,2, максимум 0,2 |
| Ошибка начала, с | медиана 0,2 (шаг выборки 5 к/с = 0,2 с) |

Разбор расхождений:
- Пропуск и одно лишнее посещение — вероятно, **одна и та же машина**: у системы `car-7` 4,0–4,6 с, вручную 4,4–4,8 с; пересечение 0,2 с из 0,8 с (IoU 0,25 < 0,3). Это машина у самой линии зоны.
- Три лишних посещения (`car-23` 6,6–9,4 с, `car-28` 8,8–11,2 с, `car-54` 13,2–14,4 с) — те самые машины, которые **едут по верхней линии зоны** и которые вручную помечены как спорные. Причина — зона выбрана неудачно: её верхняя граница совпадает с дорогой, по которой едут поперёк. Для показа это видно и честно; для пилота зону нужно проводить с запасом от потоков, которые не должны учитываться.
- Три длинных ожидания (две машины по 21,6 с и одна 13,0 с в окне) найдены, длительность отличается от ручной на 0,2 с.

## Что это значит и чего это не значит
- На этой записи и этой зоне система находит длительные стоянки в зоне с ошибкой длительности около одного шага выборки (0,2 с).
- Короткие посещения у границы зоны ненадёжны (1 пропуск из 2 размеченных и 3 спорных лишних).
- **Это не общая точность системы:** 5 посещений, одна запись, одна зона, разметка не независимая, отложенного фрагмента нет.
