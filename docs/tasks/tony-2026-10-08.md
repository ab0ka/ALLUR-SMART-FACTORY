## Т6. Сквозной автотест интерфейса в headless Edge (без npm-зависимостей)

**Ветка:** `feature/e2e-ui` · **метки:** `адаптив-доступность`, `Тони` · **касается инфраструктуры — предупредить Абзала в PR.**

```text
ЗАДАЧА: автоматическая проверка главного сценария через настоящий браузер, чтобы каждый PR
можно было проверить одной командой и получить скриншоты.

Ограничения: без новых npm-зависимостей (Puppeteer/Playwright не ставить). Использовать Microsoft Edge
или Chrome, установленные в системе, в режиме --headless=new --remote-debugging-port, и протокол
Chrome DevTools (CDP) через встроенный в Node 22+ WebSocket. Путь к браузеру — переменная окружения
BROWSER_PATH или стандартные пути Windows; если браузера нет — понятное сообщение и код выхода 0
с пометкой «пропущено» (чтобы CI без браузера не падал).

Сделать scripts/e2e-ui.mjs и npm-скрипт "e2e": "node scripts/e2e-ui.mjs":
1. Собрать проект (node scripts/build.mjs), запустить сервер на свободном порту (от 3040)
   с AI_PROVIDER=local и отдельным ALLUR_STATE_FILE=e2e.json (после теста файл удалить,
   сервер и браузер остановить в finally).
2. Сбросить смену через API (с CSRF-токеном из /api/state), открыть #space/assembly.
3. Сценарий через интерфейс (клики по элементам, не прямые POST):
   два шага «+5 минут» → на сцене появилась проблема PR-1 у СБ-2 → клик по машине на СБ-2 →
   паспорт открыт → «Диагностика поста» → запустить «Замер тока и температуры насоса» →
   подтвердить в диалоге → два шага → результат проверки в карточке → «Сравнить решения» →
   выбрать рекомендованный вариант → подтвердить → в журнале появилось решение DEC-1 →
   шаги до закрытия PR-1 (проверка восстановления) → карточка проблемы «Закрыта».
4. Проверки по ходу: нет ошибок в консоли (Runtime.exceptionThrown, Log.entryAdded level=error);
   состояние из /api/state совпадает с тем, что в карточках; повторная отправка того же решения
   даёт 409; document.documentElement.scrollWidth === innerWidth на 1280 и 390.
5. Скриншоты (Page.captureScreenshot) в screenshots/e2e/: общий вид, паспорт, диагностика,
   сравнение, решение, мобильный вид 390. Папку screenshots/e2e/ добавить в .gitignore.
6. Итог в консоли: список шагов с ✓/✗ и время; код выхода 1 при любой ошибке.
7. Описать запуск в CONTRIBUTING.md (раздел про проверки) — 3–5 строк.

Не делать: не добавлять e2e в CI-обязательные проверки (это решит Абзал); не менять код приложения,
кроме добавления data-атрибутов для надёжного поиска элементов (если без них никак — минимально
и с упоминанием в PR).

Критерии приёмки:
- npm.cmd run e2e на машине с Edge проходит весь сценарий и сохраняет 6 скриншотов.
- Без браузера выводит «пропущено: браузер не найден» и не падает.
- npm.cmd test и npm.cmd run build проходят.
```
