## Контракт раскладки цеха (П0 его фиксирует, ниже — черновик)

Файл цеха экспортирует описание; платформа рисует пол, машины, движение, таблички постов, выбор, камеру, порядок отрисовки, табличный режим и клавиатуру.

```js
// public/shops/weld.js — пример (координаты — пол цеха, как в scene.js: x вправо-вниз, y влево-вниз, единицы SVG)
export default {
  id: 'weld', stage: 'weld', title: 'Сварка',
  floor: { w: 640, h: 460 },                         // размер пола цеха
  input: { buffer: 'BACKLOG', label: 'Входной буфер кузовов', slots: [{ x: 90, y: 120 }, { x: 90, y: 200 }] },
  posts: [{ id: 'W1', x: 300, y: 90, o: 'x' }, { id: 'W2', x: 300, y: 260, o: 'x' }], // место машины на посту
  output: { buffer: 'B1', label: 'В окраску', to: 'paint', slots: [{ x: 560, y: 180 }] },
  aisles: { in: 190, out: 440 },                     // проезды, по которым машины едут между точками
  // Статичное оборудование: SVG-строка и «след» на полу для порядка отрисовки (как addStatic в scene.js).
  props: h => [ { svg: h.box(...), fp: { x0, x1, y0, y1 }, height: 70 } ],
  // Оборудование поста зависит от его состояния (работает / неисправность / ремонт): рисует Диас.
  postProp: (h, post, state) => ({ svg: '...', fp: {...}, height: 60 }),
};
```

Помощники `h` (дает платформа): `iso(x, y, z)`, `box(x, y, w, d, height, cls)`, `faceX/faceY`, классы цветов из `styles.css`. Машины — общие картинки `#sc-car-<a|b|c>-<done|body>` (Kia), их рисует платформа.
