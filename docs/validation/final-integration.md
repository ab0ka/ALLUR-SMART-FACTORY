## Локальная проверка объединённого дерева

1. Единственный полный прогон: `node --test --test-concurrency=2 tests/*.test.mjs` — **239/240 pass**, один сбой VM-окружения `tests/handover-ui.test.mjs`.
2. Причина сбоя: тест извлекает реальный action из core; после T5 этот фрагмент использует MutationObserver и document.querySelectorAll. В тестовом окружении этих API не было. Только этому тесту добавлены пустой MutationObserver и querySelectorAll, возвращающий пустой список. Производственный код после прогона не менялся.
3. Адресный повтор: `node --test --test-concurrency=2 tests/handover-ui.test.mjs` — **16/16 pass**, включая reset на той же минуте, отмену старого запроса, shiftEpoch и возврат фокуса. Полный набор повторно не запускался; результат не обозначается как полный 240/240.
4. Единственная финальная сборка: `npm.cmd run build` — **PASS**, 14 публичных ресурсов, app.js из 15 частей. WebP сохраняются как Buffer, сервер и окружение исключены из dist.
