Проверено 2026-10-08 на базе main 3773d1d. Все данные синтетические.

Карточка поста получает transfer из серверного снимка: соседние посты того же участка и доступность каждого. Проверки используют существующий transferAvailability; эта же функция повторно проверяет команду. Пустой пост, отсутствие параллельного поста и конец смены получают серверное объяснение. Клиент показывает причину рядом с недоступной кнопкой через aria-describedby. Подтверждение и requestId сохранены.
