## Исправление расхождения карточек

Воспроизведено regression: паспорт блокировал перевод на свободный снятый с загрузки пост, но объяснял это как «КК-2 — свободен», не показывая серверную причину. Обе боковые карточки теперь используют общий вывод p.transfer, без локальных эвристик. Правила движка и обработчик подтверждения не менялись.

Проверено: npm.cmd test — 91/91; npm.cmd run build — OK. Новый regression проверяет обе карточки при снятии цели с загрузки, открытой проблеме, доступном переводе и завершённой смене. Edge 1440×1000 на 3030: обе карточки показывают точные серверные причины для held/problem, запрещённых кнопок нет, отмена доступного перевода в обеих карточках сохраняет состояние, подтверждение из паспорта создаёт ровно одно событие. Ошибок JS/CSP нет. Скриншоты: screenshots/t3-held-post.png, t3-held-vehicle.png, t3-problem-post.png, t3-problem-vehicle.png.

Зависимости первой волны опубликованы: T1 #37, T4 #36, T6 #38; в эту ветку ещё не интегрированы. Полного ТЗ по-прежнему нет, финальная приёмка не завершена.
