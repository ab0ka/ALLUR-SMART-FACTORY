## Что исправлено по результатам ревью

1. Бейдж «Синтетические данные» закреплён в шапке (`position: sticky`). У блока AI-объяснения добавлена постоянная пометка синтетичности. Статус каждого ответа (NVIDIA и локального) содержит слово «синтетический».
2. Журнал инцидентов показывает участок, причину-гипотезу, рекомендацию и действие устранения без обращения к AI. Текущее узкое место отмечено на карте пунктирной рамкой и ярлыком «Узкое место», в легенде — отдельный ключ.
3. Инцидент, не завершённый к 16:00, получает статус «Не устранён к концу смены». Время окончания остаётся пустым (не выдумывается), показывается фактическое расчётное восстановление, например 16:40. Если восстановление ровно в 16:00, инцидент завершается по сценарию.
4. Без ключа локальное объяснение выдаётся при каждом запросе без ограничения частоты. С ключом сохранены лимиты (1 запрос за 10 с, 1 одновременно). Причины fallback различаются: ключ отклонён (401/403), лимит (429), ошибка сервера (5xx), другой HTTP-статус, сеть, таймаут, некорректный ответ, локальное ограничение.
5. Обычный переход по ссылке с другого сайта открывает страницу `/`. Для чужих сайтов API и статические файлы по-прежнему закрыты. Проверки Host, Origin и CSRF не ослаблены.
6. Параметры линии и сценариев заданы в одном месте (`STATIONS`, `BASE_REJECT_RATE`, `SCENARIOS[*].effect`, `lineParameters()`). Их используют симуляция, прогноз, тексты сценариев и локальное объяснение. Захардкоженные 0,86 / 0,975 / 0,57 / 0,78 удалены.
7. Обработчик ошибок явный. Ожидаемые ошибки клиента возвращают 4xx: 400 — ввод, 404 — инцидент, 409 — конфликт состояния. Непредвиденные ошибки возвращают 500 с общим текстом, в лог пишется только тип ошибки. Некорректный адрес запроса даёт 400.
8. `dist` собирается по белому списку из 4 файлов. Посторонние файлы переносятся в `build-quarantine\<время>\`, а не удаляются. Сборка отклоняет клиентские файлы, похожие на ключ NVIDIA.
9. На экранах до 800 px карта прокручивается по горизонтали внутри своей области (ширина 780 px) с увеличенными подписями.
10. Добавлены смысловые тесты на все пункты выше.

Не менялись: архитектура (нативный HTTP, ESM, без зависимостей), API, seed, формулы OEE и прогноза, числовые результаты демо.

## Браузерная проверка (фактически выполнена)

Встроенный браузер Claude Desktop, локальный сервер `http://127.0.0.1:3017` без ключа NVIDIA.

- Старт 10:00: 101 годный / 103 обработано, OEE 84,2%, прогноз 403. Узкое место на карте — сборка.
- «Остановка окраски»: прогноз 403 → 365, метка «Узкое место» на окраске. Журнал: участок «Окраска», причина, рекомендация, действие устранения, «Активен · расчётное восстановление 10:45».
- +5 минут: 10:05, выпуск 101, A 96%, OEE 80,8%.
- «Объяснить прогноз» дважды подряд: оба раза «Локальное объяснение · Ключ NVIDIA не настроен · локальный разбор синтетических данных», без сообщения об ограничении частоты. Над текстом видна пометка «Синтетические данные».
- «Устранить» + 5 минут: годных 105, обработано 107, прогноз 398. Журнал: «Устранено оператором демо» с действием. AI-объяснение помечено устаревшим.
- Конец смены: остановка включена в 15:55, после 16:00 — «0 активных · 1 не устранено», «15:55 → не устранён», «Не устранён к концу смены · расчётное восстановление 16:40 (после окончания смены)». Кнопки запуска и сценариев заблокированы.
- Desktop 1280×800: при прокрутке шапка с бейджем остаётся вверху (бейдж в зоне 10–51 px от верха).
- Mobile 375×812: ширина документа 375 px (горизонтальной прокрутки страницы нет). Область карты 319 px прокручивается до 780 px, высота подписи участка 21 px, статуса — 16 px. Шапка 62 px, бейдж виден. Журнал без выхода за край.
- Консоль: во время проверки новых ошибок нет. Ранее накопленные `ERR_CONNECTION_REFUSED` относятся к периоду, когда тестовый сервер был остановлен, а вкладка продолжала опрос; UI в это время показывал сообщение о потере связи.

## Непроверенное и ограничения

- **Реальный NVIDIA API не вызывался**: ключ не предоставлялся. Успех и ошибки проверены только на mock. Подключение аккаунта, квоту и доступность модели подтвердить нельзя.
- Снимки `demo-desktop.jpg` и `demo-mobile.jpg` сделаны при первоначальной проверке Codex и не отражают исправления (метка узкого места, закреплённая шапка, расширенный журнал). Файлы сохранены без изменений.
- Проверка мобильной вёрстки выполнена эмуляцией в браузере, не на физическом телефоне.
- Только 2D-карта; 3D/CAD нет. Условия официального кейса не сверены с отсутствующим исходным документом.
- Прогноз детерминированный сценарный, не обученная модель; диапазон ±10% будущего выпуска — эвристика.
- Упрощённая синхронная линия без буферов; OEE участков отражает общий поток, а не телеметрию оборудования.
- Нет базы, учётных записей и управления оборудованием. Состояние общее для вкладок одного процесса и сбрасывается при перезапуске. Host/CSRF-защита рассчитана на локальное демо и не заменяет production-аутентификацию.
- При остановленном сервере клиент продолжает опрос каждые 1,2 с, что засоряет консоль ошибками соединения (поведение не менялось).
