# Сценарий защиты (2–3 минуты)

**Проверенная версия:** `main` после PR #67 (`95ffe6f`) и PR с документацией.
**Адрес:** http://localhost:3000/#overview (или проверочный порт, см. README).
**Перед показом:** `npm.cmd run build`, затем `npm.cmd start`; в меню «Смена» → «Сбросить смену», если нужна чистая смена.

## 1. Обзор → данные кейса (40 с)
1. «Обзор» → переключатель **«Данные кейса»**. Метка: «Тестовые данные задания. Не подтверждённые реальные показатели Allur».
2. Показатели: план месяца 4800 против 5500 (расхождение 700), брак окраски 4,33 % при допустимых 2 %, простои 150 мин (4 записи, не весь завод), OEE — «Недостаточно данных».
3. Открыть «Брак на участке „Окраска“ выше допустимого»: факт, расчёт 10/231, гипотеза отдельно от причины, что неизвестно, следующий шаг.
4. Нажать запись **К2** → открывается таблица кейса с подсвеченной строкой → «Назад» возвращает в карточку.

## 2. Симуляция: проблема → сравнение → действие (60 с)
1. Переключатель **«Симуляция»**: план и прогноз смены, OEE сборки, простой подъёмников, задачи.
2. Открыть первую задачу (подъёмник СБ-2): измеренное отклонение, причина — гипотеза.
3. «Сравнить решения» (или «Рассчитать варианты»): сравнение считается на копии смены, сама смена не меняется. Если смена ушла вперёд, сравнение помечается устаревшим.
4. «Применить выбранное…» → подтверждение → результат в задаче и в «Результатах смены».

## 3. Отчёт и эффект (30 с)
1. «Отчёт» → «Данные кейса»: CSV и «Отчёт / PDF».
2. «Передача смены»: JSON / CSV.
3. «Эффект»: на 200 одинаковых синтетических сменах принято машин 16,99 → 17,18 за смену, отказов подъёмника 0,52 → 0,03. Деньги — только после ввода стоимости машины и числа смен, формула видна.

## 4. Видеоэксперимент (20–30 с, по желанию)
1. «Ещё» → «Видеоэксперимент» → «Пример: результаты анализа записи».
2. Метка: «Внешняя запись. Не производство Allur. Воспроизведение результатов анализа». Окно измерения 0–21,8 с: дальше камера движется.
3. Три машины выше демонстрационного порога: «Превышен демонстрационный порог присутствия; производственная причина не определяется».
4. Ручная сверка (5 посещений): совпало 4, ошибка длительности 0,2 с. Это результат на выборке, а не общая точность.

## Что можно говорить
- «Тестовые данные задания», «синтетическая симуляция», «внешняя запись».
- «Прогноз и сравнение — расчёт на копии смены, не факт».
- «Эффект измерен на 200 синтетических сменах; деньги — по введённой стоимости».

## Чего не говорить
- Реальные данные Allur, интеграция с заводом, прямой эфир с камер.
- Установленная причина дефекта или простоя.
- Точность распознавания или экономия без измерений.
